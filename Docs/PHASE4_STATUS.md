# Phase 4 — الورديات وقوالبها (مكتملة)

## قرار معماري (§36)
لا يوجد جدول `ShiftTemplates` منفصل في المخطط المعتمد (36 جدولًا): جدول `Shifts`
نفسه هو مستودع القوالب — كل صف يحمل بياناته الفعلية (الأوقات، المدة، Cross-Day،
الصنف، القواعد) وتشير إليها `MonthlyScheduleDetails`. هذا أقوى من فصل القوالب
لأن الجداول الشهرية ومحرك الحضور يستهلكان القيم الفعلية لا الأسماء (قاعدة 6).

## منجز
- **`FrmShifts.cs`** (جديد): قائمة الورديات — كود/اسم/بداية/نهاية/ليوم تالٍ/مدة/
  طبيعية/راحة داخلية/صنف/بصمة إلزامية/حالة، مع «تضمين المعطلة»، إضافة/تعديل/
  تعطيل-تفعيل/حذف آمن (حارس `Org.Manage` + Audit `Shifts.Add/Update/Delete` داخل
  ShiftBLL، والحذف يُرفض للورديات المستخدمة في جداول أو حضور).
- **`FrmShiftEdit.cs`** (جديد):
  - CrossDay و`DurationHrs` **يُشتقان في `ShiftBLL.Validate` (BR-06)** — الواجهة
    ترسل `null` ولا تخترعهما أبدًا: النهاية قبل البداية مسموحة فقط للورديات
    الممتدة فعليًا، والحد الأقصى 24 ساعة متواصلة مفروض من الطبقة الداخلية.
  - تعليق حي يعرض المدة المحسوبة وحالة «تمتد لليوم التالي» أثناء الكتابة.
  - الساعات الطبيعية تُقترح تلقائيًا من المدة وقابلة للتعديل (≤ المدة — يتحقق BLL)،
    والصفر يُفسَّر «افتراضي = كامل المدة» عبر إرسال null.
  - صنف الوردية (Office/Field/Night/Rest) عربيًا — أساس منع الخلط (BR-09) لاحقًا
    في الجدول الشهري عبر إعداد `Sch.DisableMixingCategories`.
  - وردية الراحة: بلا أوقات ومدة صفر (قاعدة FR في BLL) — تُلغي الحقول الزمنية تلقائيًا.
- **`FrmMain.cs`**: ربط قائمة «الورديات» بالشاشة الفعلية بدلًا من إشعار المرحلة.

## الفحص البنيوي الآلي
- توازن الأقواس لكل ملفات HR.UI: **ناجح**.
- منع C#6+ (`?.`, `$""`, `nameof`, pattern matching, `out var`): **ناجح** (C# 5.0).
- لا TODO/Placeholder/أجزاء ناقصة: **ناجح**.
- لا SQL داخل Forms؛ كل الكتابة عبر ShiftBLL؛ الرسائل عربية عبر Theme/BusinessException.

## خطوات الاختبار اليدوي
1. الورديات → إضافة: اترك الكود فارغًا → «كود الوردية إلزامي».
2. بداية 08:00 ونهاية 07:00 → «تمتد لليوم التالي» وتُقبل تلقائيًا (CrossDay مشتق).
3. كود «FR» مع أي مدة > 0 → «وردية الراحة يجب أن تكون مدتها صفر».
4. مدة = 25 ساعة مستحيلة بنيويًا (HH:mm محدود بـ 23:59 + حساب 1440 دقيقة).
5. محاولة تعديل وردية مستخدمة في جدول ثم حذفها → رسالة رفض الارتباط.
6. مستخدم بدون `Org.Manage`: أزرار الكتابة معطلة، والـ BLL يرفض أي محاولة.
